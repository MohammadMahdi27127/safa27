ENDPOINT 1: GET /api/mentor/collective-monitoring/?days=X
────────────────────────────────────────────────────────

✓ Permission Check:
  - Only authenticated users (manager/mentor)
  - Returns 403 if not is_manager

✓ Parameters:
  - ?days=7 (default)
  - ?days=14
  - ?days=30
  - Invalid days fallback to 7
  - If days < 1 or > 365, defaults to 7

✓ Response Data (Success 200):
  {
    "days": 7,
    "members": [
      {
        "id": 1,
        "full_name": "کریمی",
        "group_code": "27001",
        "exercise_hours": 10.5,
        "reading_pages": 150,
        "attendance_rate": 85.5,
        "growth_submissions": 7,
        "overall_score": 325.25
      },
      ...
    ],
    "count": 25
  }

✓ Metrics Calculation:
  - exercise_hours: SUM of PersonalGrowthRecord.exercise_hours
  - reading_pages: SUM of PersonalGrowthRecord.reading_pages
  - attendance_rate: Fetched from get_user_sheet_info (%)
  - growth_submissions: COUNT of PersonalGrowthRecord entries
  - overall_score = (exercise_hours × 10) + (reading_pages × 0.5) + 
                    (attendance_rate × 1.5) + (growth_submissions × 10)

✓ Error Handling:
  - 403: User not manager
  - 500: Exception in calculation (with logging)
  - Empty list if no members
  - Handles null/missing sheet_info gracefully

ENDPOINT 2: GET /api/mentor/workgroups-stats/?days=X
────────────────────────────────────────────────────

✓ Permission Check:
  - Only authenticated managers
  - Returns 403 if not is_manager

✓ Response Data (Success 200):
  {
    "days": 7,
    "workgroups": [
      {
        "id": 1,
        "name": "سازماندهی",
        "meeting_count": 3,
        "member_count": 5,
        "avg_attendance": 82.4,
        "avg_submissions": 2.5,
        "overall_score": 63.75
      },
      ...
    ],
    "count": 8
  }

✓ Metrics Calculation:
  - meeting_count: COUNT of WorkgroupMeeting records
  - member_count: COUNT of User objects with workgroup=this
  - avg_attendance: AVERAGE of attendance rates across members
  - avg_submissions: SUM of submissions / member_count
  - overall_score = (meeting_count × 5) + (avg_attendance × 1.5) + 
                    (avg_submissions × 10)

✓ Error Handling:
  - Safe division (member_count > 0 check)
  - Handles null attendance_rate
  - Empty list if no workgroups
