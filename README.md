# 🌟 سامانه صفا ۲۷ (Safa 27 Management Platform)

سامانه جامع مدیریت تشکیلاتی، رصد مصوبات، ثبت جلسات و پیگیری رشد فردی .

---

## 🚀 تکنولوژی‌ها و ابزارها

- **بک‌اند:** Python / Django / Django REST Framework
- **احراز هویت:** JWT (SimpleJWT) بر پایه کد گروهی یکتا
- **پایگاه داده:** SQLite (قابل ارتقا به PostgreSQL / MySQL)
- **فرانت‌اند:** React / TypeScript / Vite / Tailwind CSS
- **یکپارچه‌سازی خارجی:** اتصال زنده به Google Sheets (با کتابخانه gspread) برای حضور و غیاب

---

## 🔑 ویژگی‌ها و امکانات کلیدی

- **احراز هویت سفارشی:** ورود اعضا با کد گروهی و کلمه عبور هش‌شده امن.
- **سطوح دسترسی چندگانه (RBAC):**
  - **مربی (مدیر کل):** نظارت جامع بر تمامی حلقه‌ها و کارگروه‌ها.
  - **مسئول مصوبات:** ابلاغ وظایف و مصوبات به کارگروه‌ها و دریافت هشدارهای تکمیل.
  - **مسئول کارگروه:** مدیریت چک‌لیست مصوبات، ثبت صورت‌جلسه و ارسال بازخورد.
  - **اعضای عادی:** مشاهده اعضای حلقه، آمار حضور و غیاب، دسترسی به آرشیو عمومی و ثبت گزارش شبانه رشد فردی.
- **تغییر رمز عبور ایمن:** پیاده‌سازی متد هشینگ استاندارد درون صفحه پروفایل.
- **لندینگ پیج اختصاصی:** انیمیشن‌های تایپ متن، فونت‌های زیبای فارسی و طراحی کاملاً واکنش‌گرا برای نسخه اندروید و موبایل.

---

## ⚙️ راهنمای راه‌اندازی و اجرا

### ۱. پیش‌نیازها
- نصب Python (نسخه 3.10 یا بالاتر)
- نصب Node.js (نسخه 18 یا بالاتر)

---

### ۲. راه‌اندازی سریع در ویندوز
کافی است روی فایل `start.bat` دوبار کلیک کنید تا هر دو سرور بک‌اند و فرانت‌اند به صورت خودکار اجرا شوند.

---

### ۳. راه‌اندازی دستی

#### الف) بک‌اند (Django):
```bash
# ایجاد محیط مجازی
python -m venv venv

# فعال‌سازی محیط مجازی در ویندوز
venv\Scripts\activate

# نصب وابستگی‌ها
pip install django djangorestframework djangorestframework-simplejwt jdatetime gspread oauth2client pillow

# اعمال مایگریشن‌ها
python manage.py migrate

# اجرای سرور
python manage.py runserver 127.0.0.1:8000
